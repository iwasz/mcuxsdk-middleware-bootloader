# Development tools

The device Flashloader was compiled and tested with following development tools.

Firmware projects:

-   IAR Embedded Workbench for Arm® v8.50.9
-   MDK-Arm Microcontroller Development Kit (*Keil*)® 5.33 with corresponding device pack
-   MCUXpresso IDE v11.3
-   Makefiles support with GCC 9-2020-q2-update from Arm Embedded
