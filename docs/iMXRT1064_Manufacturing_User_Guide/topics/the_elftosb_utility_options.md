# Elftosb utility options

The following table lists the command line options used to create the i.MX RT bootable image.
**elftosb utility options**
| Option | Description                                                                                                                                                                  |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| \-f    | Specify the bootable image format<br>To create the i.MX RT bootable image, the usage for family argument “-f” is: “-f imx” To create the SB file, the usage is: “-f kinetis” |
| \-c    | Command file to generate corresponding bootable image For example, “-c program_flexspi_nor_hyperflash.bd”                                                                    |
| \-o    | Output file path<br>For example, “-o ivt_flashloader.bin”                                                                                                                    |
| \-V    | Print extra detailed log information                                                                                                                                         |
| \-?    | Print help info
